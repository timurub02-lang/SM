# Трек в карточке заказа

В левом блоке заказа СДЭК, под способом доставки, показывается «Трек СДЭК». Номер — ссылка на https://www.cdek.ru/ru/tracking/ с параметром order_id; открывается в новой вкладке и доступна в режиме просмотра.

Приоритет: номер текущего зарегистрированного отправления СДЭК из интеграции, затем исходный трек заказа ЛВ. UUID и внутренний номер заказа не используются как трек. Если номера нет, строка скрыта. Для Почты России и московского курьера ссылка на СДЭК не показывается. Права просмотра заказа сохраняются.
