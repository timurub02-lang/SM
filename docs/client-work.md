# Работа оператора со своими клиентами

В «Моих клиентах», в том числе «Скоро открепятся», доступны фильтры «Все», «Нужно обработать», «Перезвон запланирован», «Обработаны сегодня». Счётчики учитывают выбранную группу клиентов и поиск. В группе «В пути» фильтры обработки и отметки на карточках скрыты; выбранный ранее фильтр обработки не ограничивает этот список.

Открытие карточки не является обработкой. В «О клиенте» оператор сохраняет результат: «Дозвонился», «Недозвон» или «Перезвон» с будущей датой и временем Москвы. Завершённые звонки CRM также учитываются автоматически; незавершённые и технические ошибки не считаются обработкой. Результат виден на карточке вместе с датой и временем, ручное сохранение записывается в историю.

Будущие личные напоминания клиента исключают его из требующих обработки до наступления самого раннего напоминания, даже после смены дня. Просроченное напоминание имеет приоритет и возвращает клиента в «Нужно обработать». Без будущего перезвона обработка действует до конца московского дня. Учитываются только действия после начала текущего закрепления.

Перезвон создаёт обычное личное напоминание, доступное во вкладке «Напоминания» и в «Требуют действия» при наступлении срока. Новый результат закрывает предыдущий перезвон этого блока и уже наступившие напоминания клиента; будущие другие напоминания сохраняются. Закрепление не продлевается. Если оно закончится до перезвона, показывается предупреждение.

Результаты персональны: оператор сохраняет их только для своего клиента. Повторное сохранение устаревшей карточки отклоняется; смена владельца проверяется повторно при записи. Статусы заказов и склад не изменяются.

Клиенты с отправленными заказами исключены из всех четырёх фильтров обработки, включая «Все», и их счётчиков. Верхняя плитка «Всего клиентов» сохраняет полное количество закреплённых клиентов; клиенты с отправленными заказами доступны в плитке «В пути».

После успешного сохранения любого результата карточка клиента закрывается. При ошибке остаётся открытой. Клиенты с последним результатом «Недозвон» за текущий московский день идут в конце списка обработки, по времени результата (последний недозвон — в самом конце). Наступивший перезвон не отодвигается назад. На следующий день недозвон снова участвует в обычном порядке; фильтры обработки сохраняют свою логику.
