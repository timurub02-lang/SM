# Проект выкуп

Согласовано 15.10.2026. Чат «Таблица Выкуп» — справка по полям выгрузки; его проект не используется автоматически.

## Заказы и доступ

Первое совпадение с выбранным администратором статусом СДЭК добавляет заказ. Дата попадания неизменна; последующая смена статуса его не удаляет. Новые заказы добавляются в течение дня. Оператор видит свои, руководитель — своего отдела, администратор и выкуп — все. Только выкуп может включить руководителям видимость всех заказов. Все редактируют доступные им строки; история изменений сохраняется.

Номер заказа, трек, статус СДЭК, оператор, дата попадания, дни действий, результат, автор, отдельные карточки комментариев и СХ. Ссылки из СК открывают конкретный заказ в таблице. Историю можно искать по номеру заказа. Архивы содержат результаты, авторов и комментарии на момент сохранения.

## Правила действий

- Дата: дата от сегодня до СХ.
- НД: результат «НД» устанавливается автоматически, без выбора; на следующий день очищается.
- Отказ: однократно +2 рабочих дня (пн–пт, четверг → понедельник), только если дата не позже СХ; либо на возврат. После использованной отсрочки при отказе доступно только «На возврат». Отсрочка скрывает заказ до повторной даты. Если +2 рабочих дня позже СХ, доступно «На возврат» либо ПО.
- В работе: предполагаемая дата выкупа до СХ; календарь открывается сразу, отдельные кнопки результата не показываются. Сохранённые ранее «У курьера» остаются в истории.
- ПО: доступно с наступления СХ, дата может быть позже СХ.
- С наступления СХ доступны только отказ (на возврат / возврат) и ПО.
- Возврат вручную — только сотрудник выкупа, не администратор.
- После «На возврат» строка остаётся на следующий день; дальше только выкуп подтверждает «Возврат» в отдельной вкладке.
- Вручен также поступает из статуса DELIVERED СДЭК, автор API.

## День и Скорозвон

Ежедневно, включая выходные: 19:50 МСК — неизменяемый архив и закрытие рабочего редактирования до полуночи; 20:00 — очередь на завтра. Тестовые строки редактируются и после закрытия дня и никогда не отправляются в СК. Вручен / Возврат не отправляются и не переходят на следующий день. НД очищается; наступившие и просроченные даты сохраняются и выделяются; На возврат сохраняется.

Проект выбирает администратор сам в настройках. По умолчанию проект пустой, автоматическая отправка выключена. Никаких записей в СК без обоих условий. Состав очереди фиксируется при закрытии дня. Включение отправки после закрытия дня действует со следующего цикла.

Перед импортом проверяется вся партия, сохраняется состав старого проекта. Общие с другими проектами контакты не удаляются — операция останавливается. Неопределённый ответ или сбой прекращает цикл без автоматического повтора разрушительной операции; состояние видно в таблице. Нужна сверка перед ручным восстановлением. Поля соответствуют прежнему экспорту: оператор, номер заказа, статус, сумма, трек-ссылка, ссылка на строку CRM.

## СХ

Пока подтверждённое поле окончательного срока хранения в API СДЭК не найдено. Ручной срок доступен с указанием источника. Не подменяем его предполагаемой длительностью или датой окончания бесплатного хранения. Автоматическое получение СХ остаётся незавершённым до подтверждения поля перевозчиком.

## Подменные звонки

Администратор и выкуп прослушивают новые записи в истории заказа и подтверждают курьера для обратных звонков. Позднейшие посторонние звонки не изменяют подтверждённый номер курьера. Освобождение подменного номера снимает подтверждение. Руководитель и оператор записей и управления подтверждением не получают. Старые разговоры до включения записи восстановить нельзя.

## Подтверждение даты доставки
Новая вручную выбранная дата (Дaта, В работе с датой и ПО) сразу переводит заказ во вкладку «Подтвердить дату доставки». Вкладка и ожидающие заказы доступны администратору и сотрудникам выкупа, включая серверную проверку прав. Автоматическая дата при отказе не требует подтверждения. До подтверждения заказ не возвращается в основную таблицу и не входит в очередь СК. После подтверждения он скрыт до назначенной даты, затем появляется в основной таблице. Для работы в назначенную дату выгрузка СК готовится накануне в 20:00 МСК. Подтверждение сохраняется с автором и временем; новая дата требует повторного подтверждения. Существующие выбранные даты без отметки подтверждения также переводятся на подтверждение; уже подтверждённые даты сохраняются. Архив сохраняет ожидающие заказы с тем же ограничением доступа.


### Подтверждение возврата
Результат «На возврат» сразу переносит заказ из основной таблицы в отдельную вкладку «Подтвердить возврат», доступную администратору и сотруднику выкупа. Заказ остаётся там при смене дня. Только сотрудник выкупа завершает его результатом «Возврат». «Вручен», в том числе обновление из СДЭК, не снимает заказ из очереди возврата. После «Возврат» заказ скрывается из текущей таблицы, история и дневные архивы сохраняются. Заказы «На возврат» исключаются из подготовки очереди СК; отправка остаётся выключенной.

Просроченная неподтверждённая дата возвращает заказ в основную таблицу с сохранением самой даты и истории. Подтвердить прошлую дату нельзя. СХ на сегодня и в прошлом выделяется красным; обещанная дата остаётся жёлтой.
