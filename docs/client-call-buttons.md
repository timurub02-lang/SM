# Кнопки звонка в карточке клиента

Кнопки расположены справа вверху: светлая кнопка «МТС» без логотипа слева, зелёная «Позвонить» справа (Билайн). На узком экране кнопки размещаются под заголовком, до содержимого карточки.

Маршруты звонков, ограничения доступа и блокировка при активном звонке сохраняются. Из входящего с действующим заказом звонят из заказа.

В блоке «Работа с клиентом» доступны только «Недозвон» и «Перезвон». Результат выбирается явно перед сохранением. Исторический результат «Дозвонился» остаётся доступен для чтения.
