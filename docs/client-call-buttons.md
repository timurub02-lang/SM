# Кнопки звонка в карточке клиента

Кнопки расположены справа вверху: светлая кнопка «МТС» без логотипа слева, зелёная «Позвонить» справа (Билайн). На узком экране кнопки размещаются под заголовком, до содержимого карточки.

Маршруты звонков, ограничения доступа и блокировка при активном звонке сохраняются. Из входящего с действующим заказом звонят из заказа.

В блоке «Работа с клиентом» доступны только «Недозвон» и «Перезвон». Результат выбирается явно перед сохранением. Исторический результат «Дозвонился» остаётся доступен для чтения.

Кнопки выбора линии показаны также в заказах, проекте выкупа, возвратах, кабинете курьера и входящих. МТС слева, обычный звонок справа. Тест микрофона и тестовый звонок остаются отдельными. МТС доступен только подключённой тестовой учётной записи; наличие кнопки не подключает остальных сотрудников. Сервер проверяет доступ к исходному заказу/обращению; звонок по заказу сохраняет его связь в истории. После состоявшегося звонка МТС из входящего вызывается существующая форма итога.

Оператор может просматривать свой отменённый заказ и историю звонков после снятия закрепления клиента. Звонки из такого заказа по обеим линиям запрещены, если клиент свободен или закреплён за другим оператором. Если клиент по-прежнему закреплён за оператором заказа, отмена сама по себе не запрещает звонок. Ограничение проверяется сервером при получении номеров и запуске звонка.
