# Кнопка «Позвонить через СК»

Пилот для карточек клиента, заказа и входящего обращения. Выпуск с пустой конфигурацией сохраняет обычную работу операторов. SDK панели не загружается при входе в CRM. Карточка показывает кнопку только участнику пилота с серверным доступом к телефонии.

## Подключение сотрудника

1. Подготовьте отдельный HTTPS-хост, например `phone.smcrm.ru`. Из пакета CRM на нём должны отдаваться только `public/sk-phone/index.html` и `public/sk-phone/phone.mjs` по адресам `/sk-phone/index.html` и `/sk-phone/phone.mjs`. Для модуля нужен JavaScript MIME. Остальные пути возвращают 404. На VM100 файлы находятся в закрытом каталоге релиза `/srv/crm/current/.next/standalone/public`. Два точных пути получает Nginx через действующий web-слот, без cookies, заголовков авторизации и тела запроса. После выпуска сертификата примените [конфигурацию отдельного хоста](../deploy/sm-sk-phone.conf) и проверьте, что оба файла доступны через HTTPS, а `/api/telephony` возвращает 404. Используйте сертификат этого хоста, Cache-Control no-store и заголовок `Content-Security-Policy: frame-ancestors https://crm.smanalytics.ru https://smcrm.ru`. Если конфигурация Nginx добавляет X-Frame-Options SAMEORIGIN к статике, оставьте его только на страницах самой CRM. Не проксируйте API и cookies CRM на хост телефона.
2. На VM100 конфигурация читается из `/etc/sm-crm-sk-widget.json`. Пример содержимого: `{"origin":"https://phone.smcrm.ru","pilots":{"TEST-EMPLOYEE":"123"}}`. Ключ в `pilots` — точный ID сотрудника CRM, значение — строка с его числовым ID в Скорозвоне. Используйте атомарную замену файла с правом чтения у runtime и правом записи только у root. При отсутствии файла, ошибке чтения или пустом списке кнопка скрыта. Сервер перечитывает файл при подключении и перед каждой попыткой. Перезапуск служб не нужен. Для тестов путь можно переопределить через `CRM_SK_WIDGET_CONFIG_PATH`. Глобальная телефония CRM и её ключ выбора номеров должны быть настроены.
3. Для тестового оператора включите скрытие телефонов и назначьте исходящую линию в Скорозвоне. Подготовьте тестовый проект. Сначала зафиксируйте статус в обычном кабинете, затем нажмите «Позвонить через СК» в карточке CRM. Войдите в штатную форму. Только отдельное нажатие «Позвонить» после подключения и выбора телефона передаёт команду набора.
4. Проверьте оба направления звука, маску номера, статус обеих вкладок, историю нужной карточки и вкладку, куда попадает следующий проектный вызов. Для штатной работы с входящими в готовых интеграциях Скорозвон рекомендует закрыть кабинет. До расширения пилота подтвердите у провайдера поддержку нужного сочетания вкладок и проверьте его на тестовом проекте. Для отключения сотрудника удалите его из списка атомарной заменой файла. Новые запросы на набор перепроверяют доступ на сервере.

## Работа карточки

«Позвонить через СК» открывает панель «Телефон» в правом нижнем углу CRM. Во время разговора нажмите «Свернуть телефон», чтобы продолжить заполнять карточку. Свёрнутая кнопка показывает состояние вызова и разворачивает тот же виджет. При проверке пилота сверните и разверните панель во время разговора, проверьте звук в обе стороны и сохранность введённого текста.

Сервер принимает ID карточки и ключ выбранного телефона. Он заново проверяет доступ, закрепление, ограничения заказа и работу с входящим. Для обратного звонка по обращению первым предлагается номер звонящего, если действие карточки работает в контексте обращения. Когда CRM направляет оператора в связанный заказ или клиентскую карточку, действуют разрешения этой карточки.

Панель работает на собственном origin. Обе стороны проверяют отправителя сообщений. Перед набором панель сверяет ID вошедшего оператора и маску номеров. Полный номер передаётся браузерному SDK для звонка и доступен в инструментах разработчика. В URL и сообщениях CRM оператору номера нет. Общий ключ интеграции и пароль CRM для набора не используются.

Сервер сохраняет одну попытку в журнале телефонии. Повтор HTTP-запроса с тем же ID исключён. После нажатия при неопределённом ответе проверьте историю перед новой попыткой. При потере вкладки незавершённая попытка перестаёт блокировать новые вызовы по истечении 32 минут. Встроенная блокировка ограничивает панель одной вкладкой CRM на сотрудника. Состояния разговора, отмеченные в истории CRM, получены от браузерного виджета. Итог по сценарию оператор сохраняет у провайдера. Эта функция не создаёт заказ, не меняет его бизнес-статус и не импортирует запись разговора.
