# Т1: перенос процесса из Скорозвона

Кандидат PR #62. Сборка и синтетические проверки не подтверждают установку или живую работу телефонии. Детектор автоответчика исключён по поручению пользователя.

| Правило | Реализация | Проверка / ограничение |
| --- | --- | --- |
| База загружается из нашей CRM | Выбор листа, проверка исключений, подтверждение состава, идемпотентная загрузка | Рабочий SQL-источник требует отдельного подключения к Т1; загрузка не запускает звонки |
| Клиент не попадает в две партии | Резерв по клиенту и номеру до завершения партии | Проверены повтор запроса, конфликт номера, отмена и повторная загрузка после завершения |
| Обычная очередь 0 → 1 → 2 попытки | Выбор по числу уникальных попыток в native-истории | Обычная дата повторной попытки не повышает приоритет |
| Общий предел 3 попытки | Счётчик разных цепочек звонков; административные исключения не считаются | Смешанные занято/неответ/ошибка также достигают общего предела |
| Повторы | Занято/неответ/ошибка ≥30 мин; пропуск оператором/уход из очереди ≥5 мин; native отбой из дозванивающихся ≥60 мин | Последний код не доказывает точное соответствие SIP-отказу; нужен контроль реального отказа |
| Перезвон к назначенному времени | Только подтверждённый результат; приоритет после наступления времени | Не обходит проектное расписание, окно клиента, native задержку и лимит попыток |
| Прежний оператор | Привязка к оператору с установленным правилом освобождения через 30 минут | Проверены недоступный оператор и смена доступности; гонка выбора в native планировщике требует живой проверки |
| Часовой пояс клиента | Диапазоны телефонных номеров; при нескольких поясах пересечение разрешённых окон | Неизвестный/устаревший диапазон блокирует набор; город не подменяет проверку номера |
| Карточка и закрепление | Передача только по подтверждённому ответу; существующий владелец сохраняется | Проверены повтор событий, смена оператора и поздние события старой партии |
| Завершение партии | Приостановленный проект, нет сеансов, native итог или 3 уникальные попытки, история полностью перенесена | Архивирование своего источника, без изменения native-истории; новая партия получает новые ID |
| Недозвоны | Отдельная очередь CRM для подтверждённых «Нет ответа» и «Робот-защитник» | Без автоматической загрузки/запуска; лист и владелец сохраняются; просмотр с постраничной навигацией |
| Результат «СМ СРМ» | Промежуточный; успешным считается только «Заказ» | Частную конфигурацию списка результатов сверить при установке |
| Предиктивный режим | Используется native механизм Oktell | Синтетические тесты не подтверждают качество распределения и 3 одновременных разговора |
| Карусель исходящих номеров | Не имитируется переключением трёх каналов одного потока | Сейчас подтверждён один поток МТС без отдельных настроенных Caller ID; нужны действующие номера и разрешение провайдера |
| Операторский текст | Существующий текст не переносится автоматически | В источнике есть неподтверждённые медицинские обещания; нужна исправленная версия |
| Детектор | Исключён | Не разрабатывается и не включается |

## Установка без звонков

Сначала успешные проверки PR, затем проверенный merge/main release. Отдельно сохранить копии БД и определений процедур, установить `delivery-schema.sql`, `sql/t1-delivery-source.sql`, `sql/t1-attempt-order.sql` и разрешить `w_crm_delivery_complete`. Обновить телефонный мост при отключённых гарнитурах. Подключение внешнего источника выполняется штатным клиентом/API Oktell, без записей в A_* таблицы; проверить идентификаторы, сохранность диагностической истории и новое значение listId в частной конфигурации моста. Native задача остаётся выключенной.

После установки сверить фактический commit CRM, мост, подписи процедур, источник и отсутствие новых попыток. Проверки на fixture не выполнять на рабочей базе. Звонки и нагрузочный тест требуют отдельного поручения пользователя.
