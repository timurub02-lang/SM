Как это будет подключаться

Прототип не загружает SDK Скорозвона. События звонков имитируются; переходы, перевод и сохранение результата служат проверкой сценария.

При интеграции события call:started / ringing / connected / ended свяжем с карточкой по lead_external_id. Итоговые результаты и записи будут поступать через webhook call_result. API сохранения нашей формы и перезвона требует уточнения у поставщика.
