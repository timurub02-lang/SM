# СМ · CRM — первая рабочая версия

Закрытая версия для владельца, на вымышленных данных. Изменения хранятся в D1. Локальная база для проверок не переносится на сайт.

Работает: база клиентов, импорт XLSX с выбором листов (до 1000 строк за раз), нормализация и проверка дублей телефонов, закрепление за сотрудником, отдельные заказы и корзины, комментарии, история действий, недозвон и перезвон, обычное и дополнительное подтверждение, возвраты оператору, проверка, упаковка, Excel-накладные, карточки сотрудников, показатели выкупа.

Адрес пока вводится вручную. Скорозвон, ДаДата, СДЭК и замена телефона не подключены. Перевод в доставку заблокирован до подключения. Срок закрепления по умолчанию 30 дней — демонстрационная настройка; возврат просроченных клиентов в базу запускается вручную. Отдел выкупа и настройки каждого статуса ждут описания бизнес-правил. Псевдоним/логин сотрудника пока являются полями профиля, а не учётной записью.

Переключатель сотрудника — режим просмотра сценариев владельцем, не система разграничения прав. История сохраняет вошедшего пользователя и выбранного сотрудника отдельно в подписи. До подключения команды нужны персональные входы, серверные права и согласованные правила доступа к окладам/бонусам. Не менять owner-private доступ на общий без этих доработок.

## Локальная разработка

`npm run dev` — предварительный просмотр. Схема: `db/schema.ts`; миграции: `drizzle/`. Используется стандартный локальный вход Sites. После сборки применить миграции к `.wrangler/state` по инструкциям Sites. База предварительного просмотра требует перезапуска dev-сервера после первой миграции.

`npx tsc --noEmit` — проверка типов. `python3 tests/smoke.py` — сквозная проверка только локальной CRM на localhost:5173; создаёт вымышленные тестовые записи. Проверяет корзину, переходы, повторное/дополнительное подтверждение, обязательную причину возврата, перезвон, конфликты версий и дубли. `npm run build` — сборка.

4. Номенклатура и цены, шаблон накладной, ДаДата, замена телефона, СДЭК.
5. Отдел выкупа, расчёт бонусов и окончательная формула процента выкупа.
