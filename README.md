# СМ · CRM — первая рабочая версия

Рабочая версия на Миране: https://crm.smanalytics.ru. Исходники обновляются через GitHub,
данные хранятся в отдельной SQLite-базе на сервере. Локальный Sites-preview использует D1.

На сервере сотрудники входят по личному логину и паролю. Администратор управляет
учётными записями в «Команда», руководитель — операторами своего отдела.
Сервер проверяет права и ограничивает выдачу данных; переключатель демо-профилей
доступен только в локальном preview. После смены пароля, логина, роли, отдела
или отключения доступа прежние сеансы завершаются.

Работают база клиентов, импорт XLSX, заказы, подтверждение, доработка, упаковка,
склад, доставка, история действий и карточки сотрудников. Настройки интеграций
и рабочие данные остаются на сервере и не попадают в Git.

Развёртывание и персональный вход: [docs/miran.md](docs/miran.md).
Проверки входа: `node --experimental-strip-types tests/auth.mjs` и после Miran
standalone-сборки `node --experimental-strip-types tests/auth-http.mjs`.

## Локальная разработка

`npm run dev` — предварительный просмотр. Схема: `db/schema.ts`; миграции: `drizzle/`. Используется стандартный локальный вход Sites. После сборки применить миграции к `.wrangler/state` по инструкциям Sites. База предварительного просмотра требует перезапуска dev-сервера после первой миграции.

`npx tsc --noEmit` — проверка типов. `python3 tests/smoke.py` — сквозная проверка только локальной CRM на localhost:5173; создаёт вымышленные тестовые записи. Проверяет корзину, переходы, повторное/дополнительное подтверждение, обязательную причину возврата, перезвон, конфликты версий и дубли. `npm run build` — сборка.

## Следующие согласования

1. Скорозвон: проекты, результаты звонков, момент создания заказа и закрепления.
2. Срок владения клиентом и события, которые его продлевают.
3. Права ролей, очереди логистов, число попыток дозвона, обязательные поля статусов.
4. Номенклатура и цены, шаблон накладной, ДаДата, замена телефона, СДЭК.
5. Отдел выкупа, расчёт бонусов и окончательная формула процента выкупа.
